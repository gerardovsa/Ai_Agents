## 🔧 Core Scripts

### create_focused_timeline.py
**Type**: Main Timeline Generator (Python)  
**Status**: ⭐ PRIMARY SCRIPT  
**Usage**: `python create_focused_timeline.py`  
**Purpose**: 
- Scans project files
- Extracts timestamps
- Categorizes files
- Generates interactive HTML dashboard
**Output**: `focused_timeline_detailed.html`  
**Requires**: `config.py`

### analyze_all_work.py
**Type**: Work Hours Analyzer (Python)  
**Status**: Supporting Script  
**Usage**: `python analyze_all_work.py`  
**Purpose**:
- Analyzes file metadata
- Calculates hourly activity patterns
- Generates daily work breakdowns
**Output**: JSON with daily statistics  
**Standalone**: Yes

### calculate_actual_work_hours.py
**Type**: Hours Calculator (Python)  
**Status**: Supporting Script  
**Usage**: `python calculate_actual_work_hours.py`  
**Purpose**:
- Accurate work hours calculation
- File creation timestamp analysis
- Project-level hour tracking
**Output**: Console output with totals  
**Standalone**: Yes

### professional_timeline.py
**Type**: Alternative Timeline Generator (Python)  
**Status**: Alternative  
**Usage**: `python professional_timeline.py`  
**Purpose**:
- Simpler timeline generation
- Different visual style
- Faster processing for small projects
**Output**: `professional_timeline.html`  
**When to Use**: Lightweight, quick reports

### analyze_file_activity_timeline.py
**Type**: Activity Analyzer (Python)

**Usage**: `python analyze_file_activity_timeline.py`  
**Purpose**:
- Deep file activity analysis
- Temporal pattern detection
- Commit frequency analysis
**Output**: Console reports  
**Standalone**: Yes

## 🎯 Common Workflows

### First Time Setup
1. Read `README.md`
2. Copy `config_template.py` → `config.py`
3. Edit `config.py` with your projects
4. Run `quick_start.bat` or `quick_start.ps1`
5. View `focused_timeline_detailed.html`

### Regular Updates
1. Run `quick_start.bat` or `quick_start.ps1`
2. Browser opens with updated timeline
3. All tabs auto-populate with latest data

### Customization
1. Read `USAGE_GUIDE.md` section on customization
2. Edit `config.py` with changes
3. Regenerate timeline
4. Test in browser

### Troubleshooting
1. Check `USAGE_GUIDE.md` Troubleshooting section
2. Verify `config.py` exists and has correct paths
3. Check browser console (F12) for JavaScript errors
4. Run Python script directly to see error messages
