## ✅ NEW SYSTEM Solution

### Universal Regex Replacement
**Single-pass algorithm that updates EVERYTHING:**

```powershell
# OLD: Line-by-line with comment detection (BUGGY)
$lines = $content -split "`n"
$updatedLines = $lines | ForEach-Object {
    if ($_ -notmatch '^\s*<!--.*-->') {  # ← TOO RESTRICTIVE
        $_ -replace $versionPattern, "?v=$timestamp"
    }
}

# NEW: Universal replacement (FOOLPROOF)
$content = $content -replace '\?v=\d{8}[_\d]*[a-zA-Z]*', "?v=$timestamp"
```

**Why this works:**
- Updates **active files** (loaded by browser)
- Updates **commented files** (keeps them in sync)
- No comment detection needed
- Single regex pass = faster & more reliable

## 🔧 How It Works Now

### Step 1: Generate Fresh Timestamp
```powershell
$timestamp = Get-Date -Format "yyyyMMdd_HHmm"
```

### Step 2: Universal Replacement
```powershell
# Regex matches ALL these formats:
?v=20251124_1500      # November date
?v=20251124j          # With letter suffix
?v=20251209174222     # Long timestamp
?v=20251209_2301      # Current format

# ALL replaced with: ?v=20251209_2301
```

### Step 3: Auto-Inject HTML_VERSION Constant
**No more manual HTML editing!**

BISTART automatically injects into `<head>`:

```html
<script>
    // Auto-generated by BISTART.ps1 - DO NOT EDIT MANUALLY
    const HTML_VERSION = '20251209_2301';
    console.log('[CACHE] HTML_VERSION injected:', HTML_VERSION);
    
    // Auto-reload if cached version detected
    const cached = sessionStorage.getItem('html_version');
    if (cached && cached !== HTML_VERSION) {
        console.log('[CACHE] Version mismatch - forcing reload:', cached, '→', HTML_VERSION);
        sessionStorage.setItem('html_version', HTML_VERSION);
        location.reload(true);
    } else if (!cached) {
        sessionStorage.setItem('html_version', HTML_VERSION);
        console.log('[CACHE] Version stored:', HTML_VERSION);
    }
</script>
```

### Step 4: Atomic File Write
All changes saved in one operation - no partial updates.
