### Step 1: Open the UI

Click the **⚡ lightning bolt button** in the top right corner

### Step 3: Choose Your Workflow

**Option A: Full Email Processing** (Recommended for first use)
- Select: **"Email AI Synergy Session Planner"**
- Category: workflow_automation
- Type: full_prompt

**Option B: Quick Actions** (For daily use)
- Select: **"Process Today's Emails"**
- Category: workflow_automation

## 🛠️ Troubleshooting (Quick Fixes)

### Prompt not appearing?
**Fix:** Refresh browser (Ctrl+F5)

### Synergy cards not creating?
**Fix:** Check Flask server running:
```powershell
BISTART
```

### Documents not generating?
**Fix:** Verify Google OAuth active:
```
Click Settings > Connected Accounts > Google
```

### SQL queries failing?
**Fix:** Check database connection:
```powershell
python -c "import sqlite3; print('DB OK')"
```
