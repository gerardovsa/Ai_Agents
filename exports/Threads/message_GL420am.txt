### ❌ **ISSUE #1: Parameter Parsing Error** (CRITICAL)

**Error Message:** `'str' object has no attribute 'items'`

**What Happened:**
- Called `inhouse_calculate_quote()` multiple times with different parameter formats
- Every attempt failed with the same error
- Tried 3 different approaches:
  1. Parameters as separate object: `<parameter name="parameters">{...}</parameter>`
  2. Parameters as JSON string: `{"quantity": 100, "book_width": 148, ...}`
  3. Different product types: `perfect_bound_books` and `flyers`

**Root Cause:**
```python
# The tool's backend code is likely doing this:
for key, value in parameters.items():  # Expects dict object
    # process parameters

# But it's receiving this:
parameters = '{"quantity": 100, ...}'  # String, not dict!
```

**Why This Happens:**
- The XML parameter format `<parameter name="parameters">{...}</parameter>` may be converting the JSON to a string
- The tool isn't deserializing the JSON string back to a dict object
- This is a **tool implementation bug**, not user error
