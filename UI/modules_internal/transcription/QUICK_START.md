# 🎙️ Voice Transcription - Quick Start Guide

## 🚀 How to Use (3 Simple Steps)

### Step 1: Start Recording
Click the **microphone button** (🎤) in the chat input toolbar.

- Button turns red and shows stop icon
- Streaming container appears at bottom
- Status shows "Recording" with red pulsing circle

### Step 2: Speak Your Message
Speak clearly into your microphone.

- Text appears in real-time as you speak
- Interim results show in gray
- Final results show in white
- Container auto-scrolls to bottom

### Step 3: Insert Your Text
Click the **stop button** (⏹️) to stop recording, then:

- **Copy** (📋) - Copy transcript to clipboard
- **Insert** (⬇️) - Add to chat input (doesn't send)
- **Send** (📤) - Add to chat input AND send message

---

## 📋 Button Reference

| Button | Name | Action |
|--------|------|--------|
| 📋 | Copy | Copy transcript to clipboard |
| ⬇️ | Insert | Insert to chat input (no send) |
| 📤 | Send | Insert + send message |
| 🔄 | Auto-clear | Toggle auto-clear after insert (🟢 ON / ⚫ OFF) |
| 🗑️ | Clear | Clear all transcript text |
| ⬇️/⬆️ | Collapse | Collapse/expand container |

---

## ⚡ Quick Tips

### Auto-Clear Toggle
- **Green (ON)** - Transcript clears after Insert/Send
- **Gray (OFF)** - Transcript remains for re-use
- Setting persists after page reload

### Collapse Container
- Click **chevron icon** to minimize to header
- Saves screen space when not actively transcribing
- Click again to expand

### Multiple Inserts
- With auto-clear OFF, you can insert the same transcript multiple times
- Useful for templates or repeated phrases

---

## 🎯 Common Workflows

### Quick Message
1. Click microphone → Speak → Click stop
2. Click **Send** (📤) → Done!

### Edit Before Sending
1. Click microphone → Speak → Click stop
2. Click **Insert** (⬇️) → Transcript appears in chat input
3. Edit text as needed
4. Click regular send button

### Copy for External Use
1. Click microphone → Speak → Click stop
2. Click **Copy** (📋)
3. Paste (Ctrl+V) into any application

### Multiple Recordings
1. Record first message → Click **Insert** (with auto-clear OFF)
2. Record second message → Click **Insert** again
3. Both transcripts now in chat input
4. Send combined message

---

## 🔧 Settings

### Enable/Disable Auto-Clear
Click the **toggle icon** (🔄) to switch between:
- **ON** (green) - Clears after insert
- **OFF** (gray) - Keeps text for re-use

### Collapse/Expand Container
Click the **chevron icon** (⬇️/⬆️) to:
- Minimize container to header only
- Expand to show full transcript

---

## 🐛 Troubleshooting

### Microphone Not Working
1. Allow microphone permission in browser
2. Check system microphone settings
3. Try refreshing the page

### Text Not Appearing
1. Check Whisper backend is running
2. Verify internet connection
3. Check browser console for errors (F12)

### Can't Find Microphone Button
1. Refresh page (Ctrl+Shift+R)
2. Look for 🎤 icon before attach button (📎)
3. Check you're on AI Prime interface
