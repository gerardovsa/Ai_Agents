# Background Effect Demos

Visual effect demos for login and loading screens.

## 📁 Demo Files

1. **background-demo-gradient-particles.html**
   - Animated gradient background
   - Floating particle system (100 particles)
   - Smooth, modern feel
   - **Best for:** Professional AI platform aesthetic

2. **background-demo-grid-network.html**
   - Animated grid background
   - Network nodes with connecting lines
   - Glowing intersection points
   - **Best for:** Tech/enterprise feel

3. **background-demo-glassmorphism.html**
   - Glassmorphism (frosted glass) effect
   - Floating color orbs
   - Noise texture overlay
   - **Best for:** Premium/modern look

4. **background-demo-wave-pattern.html**
   - Animated wave layers
   - Multiple wave frequencies
   - Smooth, fluid motion
   - **Best for:** Clean, professional feel

5. **background-demo-matrix-rain.html**
   - Matrix-style falling characters
   - Binary/Japanese characters
   - Tech/hacker aesthetic
   - **Best for:** Sci-fi/tech enthusiast look

## 🎯 How to View

1. Open any HTML file directly in your browser
2. Each demo shows a login/loading screen mockup
3. All effects are fully animated

## 🎨 Customization

All effects use CSS variables that match your platform's theme:
- Primary color: `#58a6ff` (blue)
- Success color: `#3fb950` (green)
- Background: `#0d1117` (dark)

## 💡 Performance

- All effects use CSS animations + Canvas API
- Optimized for 60fps
- Minimal CPU usage
- No external dependencies

## 🔧 Implementation

To apply to your platform:
1. Choose your preferred effect
2. Copy the CSS and JavaScript
3. Integrate into `business-ai-platform-v2.html`
4. Apply to `.auth-loading-overlay` and `.login-overlay`
