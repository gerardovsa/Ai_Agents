# Test HTML Files

This folder contains standalone HTML files used for visual testing and debugging.

## Files

- **badge-test.html** - Visual reference for badge styling and CSS classes
- **debug-agent-threads.html** - Debug visualization for agent thread states

## Note

These files are NOT part of the main application runtime. They are for:
- Visual design testing
- CSS class examples
- Debug visualization

The main application is `business-ai-platform-v2.html` in the parent `UI/` directory.
