# 📏 Google Docs Spacing Guide - Quick Reference

**Last Updated:** October 27, 2025

---

## 🎯 Core Rule: Lists Need Manual Spacing

**Automatic Spacing (Built-in):**
- ✅ Headings (`#`, `##`, etc.)
- ✅ Horizontal lines (`---`, `***`, `___`)
- ✅ Tables (`| Header | Data |`)

**Manual Spacing Required:**
- ❌ Bulleted lists (`- item`)
- ❌ Numbered lists (`1. item`)
- ❌ Body paragraphs (when adjacent to lists)

---

## ✅ Correct Spacing Pattern

```markdown
This is a paragraph of body text that introduces the topic.

- List item 1
- List item 2
- List item 3

This is another paragraph that continues after the list.
```

**Result:** Clean, readable document with proper visual separation

---

## ❌ Incorrect Spacing Pattern

```markdown
This is a paragraph of body text that introduces the topic.
- List item 1
- List item 2
- List item 3
This is another paragraph that continues after the list.
```

**Result:** Cramped, hard-to-read document with poor visual flow

---

## 📋 Complete Example

```markdown
# Project Overview

Our project has three main objectives that guide our work.

## Main Objectives

- Improve customer satisfaction
- Increase revenue by 20%
- Launch new product line

We achieved these goals through focused execution and team collaboration.

## Key Results

| Metric | Target | Actual |
|--------|--------|--------|
| NPS    | 50     | 62     |
| Revenue| $1M    | $1.2M  |

The results exceeded expectations in all categories.

1. Customer feedback was overwhelmingly positive
2. Revenue growth surpassed our stretch goals
3. Product launch received industry recognition

Moving forward, we will build on this success.
```

**Notice:**
- Empty line before each bulleted list ✅
- Empty line after each bulleted list ✅
- Empty line before numbered list ✅
- Empty line after numbered list ✅
- NO empty lines needed around table (automatic spacing) ✅
- NO empty lines needed after headings (automatic spacing) ✅

---

## 🚀 AI Instructions

When generating markdown for Google Docs:

1. **Before any list:** Add empty line
2. **After any list:** Add empty line
3. **Before tables/headings:** No empty line needed (automatic)
4. **After tables/headings:** No empty line needed (automatic)

**Quick Check:** If you see a list item directly touching body text, add an empty line.

---

## 💡 Why This Matters

- **Readability:** Empty lines create visual "breathing room"
- **Professionalism:** Well-spaced documents look more polished
- **Scannability:** Readers can quickly identify list items
- **Consistency:** Matches standard document formatting practices

---

**Remember:** When in doubt, add the empty line. Extra spacing around lists is always better than cramped text.
