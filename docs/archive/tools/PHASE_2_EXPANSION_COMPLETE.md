## 🎨 Tool Design Patterns

All new tools follow MCP-compatible format:
- ✅ Detailed parameter descriptions with types
- ✅ Required vs optional parameter specification
- ✅ Default values where applicable
- ✅ Return type documentation
- ✅ Comprehensive examples for complex operations
- ✅ Platform-specific best practices

### Example Pattern:
```json
{
  "name": "stripe_create_payment_intent",
  "platform": "stripe",
  "parameters": {
    "amount": {
      "type": "integer",
      "description": "Amount in smallest currency unit (e.g., cents for USD)",
      "required": true
    },
    "currency": {
      "type": "string",
      "description": "Three-letter ISO currency code (e.g., 'usd', 'eur', 'gbp')",
      "required": true
    }
  },
  "returns": {
    "type": "object",
    "description": "Payment intent object with client secret"
  }
}
```
