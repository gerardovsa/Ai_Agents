### 3.4 Historical (341 — dated 2025 or earlier)

Filename contains a date stamp `_NOV\d+`, `_DEC\d+_2025`, `_OCT\d+_2025`, `_2025-\d{2}-\d{2}`, etc. (compiled regex with full month list per row-50 precedent).

### 3.5 Debug (29 — analysis/research content)

Filename matches `*_ANALYSIS_*.md`, `*_INVESTIGATION.md`, `*_RESEARCH_*.md`, `*_AUDIT_*.md`, `*_DEEP_DIVE_*.md`, `*_EVALUATION*.md`, etc. AND title contains `analysis`/`investigation`/`evaluation`/`research`/`deep dive`/`audit`/`case study`/`whitepaper` keywords.

### 3.6 Suspicious (433 — no pattern matched)

**The largest bucket (35% of the set).** These are topic-prefixed one-shots named after a feature, with no filename pattern matching the typical "fix/progress/summary" suffixes. Examples: `AI_AGENTS.md`, `ARCHITECTURE.md`, `THREAD_SYSTEM.md`, `VECTOR_DATABASE.md`, `SYNERGY_COLLABORATION.md`, `AUTOMATION_WORKFLOWS.md`, `TRANSCRIPTION.md`, `MODULES.md`, `QUOTE_CALCULATOR.md`, `INHOUSE_PRINT.md`, `INHOUSE_KANBAN.md`, `PROMPT_CATALOGUE.md`, `MEMORY_SEMANTIC_SEARCH_SYSTEM_DESIGN.md`, `FILE_PROCESSING_ARCHITECTURE.md`, `TEAM_AUTHENTICATION_ARCHITECTURE.md`, `SUPABASE_CLI_GUIDE.md`, `MODULE_METADATA_STANDARD.md`, etc.

The Suspicious bucket is the highest-risk for false positives — some look canonical. See §4 for the inbound-reference audit that confirmed they are all de-facto one-shots.

**Conclusion:** None of the 433 "Suspicious" files are referenced from any active production doc. The 14 hits from `AI_DOCUMENTATION_CONSOLIDATION_INSTRUCTIONS.md` are a meta-instruction (which itself is a candidate for the next cleanup round, but not this one). The 8 hits from `System_Architexture.prompt.md` are a *generator* prompt, not a *reader* of the file.

Per CLAUDE.md §16.4 (single-source-of-truth) and §16.8 (doc safety: never delete a file just because it looks old), the absence of inbound references is the load-bearing evidence. Per §16.3 (Historical: dated, specific to a moment), the topic-prefixed files are de-facto one-shots named after topics — they would only be Canonical if they were actively read, and they are not.

The 433 files were therefore archived to `archive/timelines_and_reports/`.
